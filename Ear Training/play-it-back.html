First-try notes

How it listens. Any octave counts, so it works for banjo, fiddle, guitar, whistle or voice. It waits on each note until you find it — a wrong note shows in red and counts as a slip, but you’re never stuck. A note left ringing won’t count twice — each note has to be played. Headphones or a quiet room help.
